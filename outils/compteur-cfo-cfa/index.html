Nouveau repère

Cliquez Encadrer un symbole, puis tracez un rectangle serré autour d'un symbole — dans le tableau de légende du plan, c'est l'idéal.

Réglages du repère sélectionné

Stabilité du comptage—

Occurrences retenues selon le seuil. Un palier large signale un comptage robuste : placez-vous au milieu. Cliquez dans le graphique pour y régler le seuil.

Correction manuelle

Un plan n'est jamais parfait : ajoutez les symboles manqués, retirez les faux positifs. Les corrections survivent aux changements de seuil.

Image analysée

0 = seuil automatique (Otsu). Montez-le si des traits fins disparaissent, baissez-le si le fond est sale.

Compter un libellé

AutoCAD

DXF R12 en millimètres, un calque par repère. Repères comptés : les points relevés, à superposer à votre fond de plan. Plan vectorisé : la géométrie du PDF convertie en lignes, polylignes et textes — l'équivalent de l'import PDF d'AutoCAD. Ouvrez puis enregistrez en DWG.

Image et projet

Le projet contient vos repères, seuils et corrections — rechargez-le sur un autre folio ou un autre lot pour compter à l'identique.

Méthode

1. Ouvrez le PDF du plan (CFO ou CFA).
2. Onglet Textes d'abord : si les étiquettes sont du vrai texte, le comptage est exact. L'inventaire vous donne tout de suite la liste des libellés.
3. Pour les symboles graphiques, onglet Symboles : encadrez le symbole dans le tableau de légende, puis ajustez le seuil.
4. Vérifiez à l'œil, corrigez à la main, exportez.

Régler le seuil

Le curseur filtre instantanément : la détection n'est calculée qu'une fois. Descendez jusqu'à voir apparaître les faux positifs, puis remontez d'un cran. Les symboles traversés par un câble ont beaucoup d'encre en plus : baissez la pénalité surplus d'encre.

Confidentialité

Tout le traitement a lieu dans votre navigateur. Aucun plan n'est envoyé sur un serveur — rien ne sort de votre poste.

Limites

Le comptage par image est une aide au métré, pas un relevé contractuel : contrôlez toujours le résultat à l'écran. Un symbole trop petit (moins de 8 px à la résolution choisie) ou noyé dans un aplat se détecte mal — montez la finesse de rendu.
